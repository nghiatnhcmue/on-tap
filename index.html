Cài Đặt Xác Thực Google Bằng Firebase Auth

Đăng nhập tài khoản Google trực tiếp qua Firebase

Dán mã Web API Key từ Firebase Console của Thầy để kích hoạt cửa sổ Popup đăng nhập tài khoản Google chính thức trên TinHocHub:

Khóa Web API Key lấy từ Firebase Console (bắt đầu bằng AIzaSy...).

Hướng dẫn kích hoạt Google Sign-In trong Firebase (2 phút):

1. Vào Firebase Console → Chọn dự án của Thầy.

2. Chọn menu Authentication → Tab Sign-in method → Bấm Google → Bật Enable và Lưu.

3. Vào Project Settings (Bánh răng) → Tab General → Cuộn xuống mục Your apps → Sao chép Web API Key (bắt đầu bằng AIzaSy...) dán vào ô trên.
